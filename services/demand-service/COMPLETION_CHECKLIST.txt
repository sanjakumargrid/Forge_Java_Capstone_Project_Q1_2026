REPOSITORY QUERY METHODS ADDED (6)

1. countNonCancelledDemands(dateFrom, dateTo, businessUnit)
   → SELECT COUNT for non-cancelled demands (status NOT IN CANCELLED, DUPLICATE)

2. countFilledDemands(dateFrom, dateTo, businessUnit)
   → SELECT COUNT DISTINCT for filled demands (checked via status_history)

3. getAverageTimeToFillDays(dateFrom, dateTo, businessUnit)
   → SELECT AVG for days between created_at and first FILLED_* transition

4. countFilledInternalDemands(dateFrom, dateTo, businessUnit)
   → SELECT COUNT for closure_reason = 'FILLED_INTERNAL'

5. countFilledExternalDemands(dateFrom, dateTo, businessUnit)
   → SELECT COUNT for closure_reason = 'FILLED_EXTERNAL'

6. getCapacityByProjectClient(dateFrom, dateTo, businessUnit)
   → SELECT project_id, account_id, COUNT GROUP BY
