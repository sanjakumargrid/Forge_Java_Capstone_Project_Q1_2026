Quick layer summary:
- config      -> application setup and infrastructure wiring
- controller  -> REST API entry points
- service     -> business logic and orchestration
- domain      -> core models, enums, and state machine
- repository  -> database access layer
- dto         -> API request/response models
- kafka       -> async event publishing and listening
- client      -> external service integrations
- exception   -> custom errors and handlers
- mapper      -> data conversion between layers
